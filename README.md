# Infra Equipo

## Descripción

Proyecto de infraestructura TI desarrollado con Docker Compose.

## Servicios

- **Nginx:** servidor web.
- **Node.js:** ejecución de la aplicación.
- **MariaDB:** base de datos.
- **Redis:** almacenamiento en memoria.

## Semana 9: Automatización y supervisión en Linux

Esta práctica reúne scripts de Python y Bash orientados a la consulta del estado del sistema, la generación de alertas y la realización de respaldos. Su objetivo es practicar la automatización de tareas administrativas en Linux y documentar su funcionamiento mediante Git y GitHub.

**Archivos principales:**
- `estado.py`: consulta información del sistema, según su implementación.
- `mi_alerta.sh`: realiza tareas relacionadas con alertas.
- `mi_respaldo.sh`: ejecuta tareas relacionadas con respaldos.
- `README.md`: contiene la documentación y las instrucciones de la práctica.
