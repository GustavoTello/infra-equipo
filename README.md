# Infra Equipo

## Descripción

Proyecto de infraestructura TI desarrollado con Docker Compose para desplegar y administrar múltiples servicios mediante contenedores.

## Servicios

- Nginx
- Node.js
- MariaDB
- Redis
- Adminer
- Dozzle

## Requisitos

- Debian Linux
- Docker
- Docker Compose
- Conexión a Internet

## Instalación

Clonar el repositorio:

```bash
git clone git@github.com:GustavoTello/infra-equipo.git
cd infra-equipo


## Control de versiones

Este proyecto utiliza Git para controlar los cambios de la infraestructura y GitHub como repositorio remoto para respaldo y colaboración.

La infraestructura se organiza mediante Docker Compose, permitiendo administrar los servicios de forma conjunta.
